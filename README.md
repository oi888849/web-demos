# 交互演示集 · Demos

两个单文件、零依赖、可离线运行的交互式网页演示，统一托管在 GitHub Pages。

## 在线访问

GitHub Pages 部署后根地址：`https://oi888849.github.io/web-demos/`

- 🦟 智能精准灭蚊系统 → `https://oi888849.github.io/web-demos/mosquito/`
- 🍅 番茄钟 · 专注 → `https://oi888849.github.io/web-demos/pomodoro/`

## 目录结构

```
web-demos/
├── index.html              # 落地页（链接到两个演示）
├── mosquito/index.html     # 智能灭蚊演示 v12（约 1.5 MB）
├── pomodoro/index.html     # 番茄钟 · 专注（约 27 MB，内联音频/图片）
└── README.md
```

## 本地运行

直接用浏览器打开 `index.html` 即可；各演示也可单独打开对应 `index.html`。

## 说明

- 两个演示均为单文件、无外部依赖、可离线运行。
- 番茄钟原文件来自已发布的 WorkBuddy 应用（`app.workbuddy.link/pomodoro.html`），此处为其 GitHub 镜像。
